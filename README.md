# Dekon v3 — فروشگاه دکون

پروژه کامل React 19 + Vite 7 + Tailwind CSS 4 با صفحه اصلی، جزئیات محصول، سبد خرید، آدرس، درگاه نمایشی، پروفایل و سفارش‌ها.

## اجرا

1. Node.js نسخه سازگار با Vite 7 (20.19+ یا 22.12+) نصب باشد.
2. در پوشه پروژه دستور `npm install` را اجرا کنید.
3. سپس `npm run dev` و برای بررسی خروجی `npm run build`.

## ساختار

- `src/main.jsx`: نقطه ورود React، Router و Provider
- `src/App.jsx`: هدر، فوتر، صفحه اصلی و مسیرها
- `src/pages/ProductDetail.jsx`: گالری و جزئیات هر محصول
- `src/pages/Cart.jsx`: سبد خرید و محاسبه قیمت
- `src/pages/Checkout.jsx`: دریافت آدرس
- `src/pages/Payment.jsx`: درگاه کاملاً آزمایشی، بدون اتصال بانکی
- `src/pages/PaymentSuccess.jsx`: تأیید سفارش
- `src/pages/Profile.jsx`: سفارش‌ها و پیگیری نمایشی
- `src/context/StoreContext.jsx`: مدیریت سبد، سفارش‌ها، تم و زبان با localStorage
- `src/services/pricing.js`: محاسبات قیمت و تخفیف
- `src/services/checkout.js`: شبیه‌سازی پرداخت و ساخت سفارش
- `src/services/products.js`: سرویس محصولات؛ محل جایگزینی JSON با API در آینده
- `src/data/products.json`: اطلاعات محصولات و تصاویر

## نکات مهم

- کاربر فرضی وارد شده است؛ ثبت‌نام و احراز هویت واقعی وجود ندارد.
- اطلاعات سفارش و آدرس در مرورگر ذخیره می‌شود و ممکن است با پاک‌کردن داده مرورگر از بین برود.
- هیچ اطلاعات بانکی دریافت یا پردازش نمی‌شود؛ دکمه پرداخت فقط شبیه‌سازی موفقیت است.
- مبلغ قابل پرداخت برابر مجموع قیمت تخفیف‌خورده × تعداد است؛ تخفیف برابر اختلاف قیمت قبلی و فعلی × تعداد است.
- در محیط واقعی، قیمت و موجودی و پرداخت باید سمت سرور دوباره بررسی شوند.
- فایل‌های قدیمی را با این پروژه جایگزین کنید؛ node_modules را از ZIP منتقل نکنید.

## اصلاح فاصله بنرها در دسکتاپ
در `src/App.jsx`، کامپوننت `Hero`، ارتفاع ستون اصلی و ستون کناری در نمایشگرهای بزرگ برابر 410px شده است. علت فاصله خالی نسخه قبل، استفاده از `lg:grid-rows-2` در گرید والد همراه با `lg:row-span-2` و `lg:max-h-[410px]` در بنر اصلی بود؛ ارتفاع ردیف‌های گرید بیشتر از ارتفاع محدودشده بنر می‌شد. حالا گرید والد ردیف ثابت ندارد و هر دو ستون در دسکتاپ هم‌ارتفاع‌اند. کلاس‌های موبایل تغییر نکرده‌اند.


## نسخه ۴: ورود و ثبت‌نام نمایشی
- مسیر `/auth` برای ورود/ثبت‌نام؛ مسیرهای `/cart`، `/checkout`، `/payment` و `/profile` محافظت می‌شوند.
- بعد از ورود کاربر به مسیر مورد نظرش بازگردانده می‌شود.
- حساب‌های نمونه و رمزها در localStorage نگهداری می‌شوند: **فقط برای توسعه محلی**. این روش برای سایت واقعی امن نیست.
- قبل از انتشار باید ثبت‌نام و ورود به بک‌اند امن با هش رمز سمت سرور، نشست امن، محدودسازی تلاش ورود و تأیید شماره منتقل شود.
- سفارش‌ها و سبد خرید در این نسخه همچنان محلی و نمایشی هستند.

## نسخه ۵ — پروفایل قابل ویرایش
- نام ثبت‌شده در هدر و پروفایل نمایش داده می‌شود.
- نام، نام خانوادگی و شماره موبایل در صفحه پروفایل قابل ویرایش‌اند.
- `src/services/auth.js` داده آزمایشی را ویرایش می‌کند؛ `StoreContext` نشست فعلی را همزمان به‌روز می‌کند.
- ورود آزمایشی برای استفاده واقعی امن نیست. رمزهای واقعی کاربران را دریافت نکنید.
